# Documentação do projeto de extensão

Artefatos que acompanham o projeto "Solução colaborativa de doações e divulgação de pontos de coleta
para pessoas em vulnerabilidade" (UNIASSELVI, Prestação de Serviços, ODS 1). Cada documento descreve o
que **existe no código**; o que ainda não existe aparece marcado como lacuna.

| Documento | Etapa da metodologia | Conteúdo |
|---|---|---|
| [mapeamento-3c.md](mapeamento-3c.md) | g — implementação | Onde cada "C" do Modelo 3C (Comunicação, Coordenação, Cooperação) e o mecanismo de percepção aparecem no sistema |
| [requisitos.md](requisitos.md) | e — especificação de requisitos | Requisitos funcionais e não funcionais, rastreados até os endpoints |
| [uml.md](uml.md) | f — especificação e análise | Casos de uso, classes de domínio, atividades e sequência (Mermaid) |
| [usabilidade-nielsen-material.md](usabilidade-nielsen-material.md) | h — verificação e validação | Avaliação heurística (Nielsen), aderência ao Material Design e acessibilidade |
| [validacao-com-usuarios.md](validacao-com-usuarios.md) | d, g, h — validações presenciais | Roteiro e quadro para registrar as validações com a comunidade (a preencher) |

O guia operacional de produção (VPS, Caddy, backup) está em [deploy-hostinger.md](deploy-hostinger.md); a visão geral do sistema, em [../README.md](../README.md).

Os diagramas são Mermaid e renderizam direto no GitHub e no VS Code.
